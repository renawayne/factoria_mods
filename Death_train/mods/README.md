# Death_train — пользовательские моды

Помещайте сюда только ZIP-файлы модов, которые должны синхронизироваться через GitHub.

Требования к каждому ZIP:
- стандартное имя Factorio, например `MyModifiedMod_1.0.0.zip`;
- файл `info.json` находится в корне архива;
- в `info.json` есть поле `name`, содержащее внутреннее имя мода.

Обычные моды из Factorio Mod Portal сюда добавлять не нужно.
